GREEN LEGACY PAKISTAN WEBSITE

How to use:
1. Unzip the folder.
2. Open index.html in any modern browser.
3. The website works without a server and is mobile-friendly.
4. The two supplied GLP images are kept unchanged in the assets folder.
5. To publish it online, upload the whole folder to a web host.

The navigation includes Home, About, Mission, Team and Contact.
The English/Urdu button switches the website language.
